# Personal CV Website

## About the Project
This project is a personal Curriculum Vitae (CV) website created to showcase my personal profile, educational background, technical skills, projects, and achievements. It serves as my online portfolio for future internship and employment opportunities.

## Features
- **Personal Profile** – Introduces me and my career objectives.
- **Education** – Displays my educational background.
- **Technical Skills** – Highlights my programming and technical skills.
- **Projects** – Showcases my academic and personal projects.
- **Experience and Leadership** – Presents relevant academic project experience.
- **Certifications** – Displays my earned certifications.
- **Contact Information** – Provides ways to contact me.
- **Responsive Design** – Adapts to different screen sizes.
- **Interactive Elements** – Includes navigation, animations, and a back-to-top button.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the different sections of the website.
